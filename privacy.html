개인정보 안내

시행일·마지막 수정일: 2026년 11월 9일

이 안내는 ‘마키의 쇼츠’ 채널 운영자 본인이 사용하는 로컬 영상 제작·게시 프로그램과 이 공개 안내 웹사이트에 적용됩니다. 이 프로그램은 YouTube API 서비스를 사용합니다. Google에서 처리하는 정보에는 Google 개인정보처리방침도 적용됩니다.

접근하는 정보와 목적

  • Google OAuth 승인으로 발급된 접근·갱신 토큰: 운영자가 승인한 YouTube 작업을 수행하기 위해 사용합니다. Google 계정 비밀번호는 수집하지 않습니다.
  • 본인 채널 ID와 이름, 영상 ID·제목·설명·태그·분류·언어, 공개·예약·처리 상태와 AI 사용·시청자층 설정: 채널 일치, 업로드 결과 및 게시 설정을 확인합니다.
  • 운영자가 선택한 영상 파일과 게시 정보: YouTube 업로드와 승인한 공개·예약 변경에 사용합니다.
  • 로컬 콘티·원본 장면·편집본·검수 기록·파일 해시·전송 재개 기록: 제작, 오류 복구와 중복 업로드 방지에 사용합니다.

처리·보관 위치와 기간

영상 생성과 편집은 운영자 컴퓨터에서 처리합니다. 인증 파일은 접근 권한을 제한한 로컬 폴더에 보관하고 공개 저장소에 넣지 않습니다. 콘티·영상·검수·전송 기록은 해당 로컬 작업 폴더에 보관합니다. 운영자가 연결 또는 자료를 삭제할 때까지 필요한 자료를 보관하며, 불필요해진 API 정보는 삭제합니다. YouTube에 올라간 영상은 YouTube에서 별도로 관리됩니다.

공유와 제한

승인한 영상과 게시 정보를 Google YouTube API에 전송합니다. Google 계정 데이터나 OAuth 토큰을 판매하거나 광고 타기팅·신용평가·범용 AI 학습에 이용하지 않습니다. 다른 이용자나 외부 생성 서비스에 계정 정보를 공유하는 기능은 없습니다.

이 앱의 Google API 정보 사용·전송은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 따릅니다.

연결 철회·자료 삭제

Google 계정의 서드 파티 연결 관리에서 이 앱의 접근 권한을 철회할 수 있습니다. 권한을 철회한 뒤 로컬 자동 실행을 멈추고 인증 파일을 삭제하면 해당 컴퓨터의 연결 자료가 제거됩니다. 로컬 콘티·영상·검수·전송 기록은 운영자가 파일별 또는 작업 폴더별로 삭제할 수 있습니다. YouTube의 업로드 영상은 YouTube Studio에서 별도로 관리해야 합니다. 앱에는 영상 삭제 명령이 없습니다.

이 웹사이트

이 안내 웹사이트에는 로그인·개인정보 입력·분석 추적 코드를 두지 않습니다. 웹 호스팅 제공자 GitHub는 서비스 제공·보안을 위해 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보 안내를 참고하세요.
