이 앱은 무엇을 하나요?

‘마키의 쇼츠’ 로컬 제작 도구는 채널 운영자의 컴퓨터에서 콘티와 동물 영상을 만들고, 자막과 자체 음향을 편집한 뒤 YouTube에 올리는 개인용 프로그램입니다. YouTube Data API를 사용해 운영자의 채널과 영상 상태를 확인하고, 승인한 파일을 업로드하거나 공개·예약 상태를 바꿉니다.

채널 운영자 본인용 도구입니다.

이 웹사이트는 앱과 데이터 처리 방식을 안내합니다. 웹사이트에서 Google 로그인이나 영상 업로드를 받지 않습니다. 실제 Google 연결은 운영자 컴퓨터의 별도 프로그램에서 본인 동의로 진행합니다.

어떤 권한을 사용하나요?

YouTube 영상 업로드, 본인 채널·영상 정보 읽기, 승인한 영상의 공개·예약 상태 변경에 필요한 권한을 사용합니다. Google이 제공하는 수정 권한에는 더 넓은 영상 관리 권한이 포함되지만, 현재 프로그램은 영상 삭제 기능을 제공하지 않습니다.
